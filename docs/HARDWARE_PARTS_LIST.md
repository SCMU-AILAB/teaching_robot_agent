# 小车配件清单（2026-10-19）

## 方案概要

- 结构：两轮差速驱动，前后各一个万向轮，四点支撑；外壳 3D 打印。
- 控制：Jetson Orin NX 8GB 运行 Agent、语音和相机；ESP32-C6 负责电机 PWM、编码器计数、速度 PID 和看门狗，两者通过 USB 串口通信。固件用 Rust（esp-hal）。
- 供电：Jetson 使用自带的 19V 电池；电机使用现有的 12V 电池；ESP32 从 Jetson 的 USB 取电。

```
19V Jetson 电池 ──→ Jetson Orin NX
                        │ USB（同时供电和串口通信）
                        ↓
                      ESP32-C6 ──3.3V──→ 编码器 ×2、BMI088
                        │ PWM / 方向信号
12V 电池 ─保险丝─总开关─急停─→ 电机驱动板 ──→ 电机 ×2
                        ↑
            驱动板的地与 ESP32 的地相连（信号要有共同的参考地）
```

接线要点：

- 只连两块电池的地，正极绝对不能接在一起。
- 编码器用 3.3V 供电，输出才能直接接 ESP32。
- 急停开关直接切断电机电源，不经过任何软件。

## 结构设计要点

- 重心压低：12V 电池放最底层、两个驱动轮之间；Jetson 放中间层；摄像头、音箱放顶部。
- 车身高度不超过两个驱动轮间距的 1.5 倍左右。
- 外壳做圆角；固件限速（建议不超过 0.3 m/s）并限制加速度（建议不超过 0.5 m/s²）。

## 下单前要先确认

1. **12V 电池的类型和满电电压**：决定第 5 项买 TB6612 还是 DRV8871；同时确认最大持续放电电流不低于 6A、带保护板。
2. **电机轴径**：决定第 3 项联轴器的孔径。
3. **载板缺哪些接口**：决定第六类外设要不要买。
